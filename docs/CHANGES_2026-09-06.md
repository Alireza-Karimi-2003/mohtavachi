# Changes — 2026-09-06 (v7)

- Redesigned the Ideas prompt from scratch: one concrete idea + one compact end-to-end execution process.
- Removed length selection from Ideas, Rewrite, Post, Story, Reel, and Product Intro; only Caption keeps Short/Medium/Long.
- Caption and Reel default to two variants; other generators default to one, with up to two when explicitly requested.
- Reel two-variant generation now requires materially different concepts, hooks, visual structures, and pacing.
- Added active Image Generation to the Content menu; image editing is not included because the current provider route does not support it.
- Added free Ideas limit: 1 per day.
- Free Content Pack remains limited to 1 per week, with the next available date shown when the quota is exhausted.
- Removed weekly pack information from Status.
- Improved Status with account, quota, profile, streak, and credit information.
- Added Ollama keep-alive and generation limits to reduce repeated model loading and runaway output.
- Pack prompt redesigned around a coherent 7-day theme and connected daily content.

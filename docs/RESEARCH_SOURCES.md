# Research notes — 2026-09-04

## Telegram
- Telegram Bot API is actively maintained; Bot API 10.3 was released Aug 24, 2026.
- Telegram reports 400M+ monthly bot/mini-app users in its Stars launch article.
- Telegram supports affiliate programs for mini apps and referral/deep links for bots.
- Digital goods/services in Telegram are sold using Telegram Stars.
